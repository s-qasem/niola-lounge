# Niola Lounge ✨

A modern, responsive website and content management experience built for Niola Lounge.

🌐 **Live Website:** https://niola-lounge.vercel.app

---

## ✦ About the Project

Niola Lounge is a real-world web project designed to create an elegant digital presence while keeping the website practical and easy to manage.

Rather than building only the customer-facing pages, I also developed an administration experience that allows website content to be managed without constantly editing the codebase.

The project gave me experience working across the interface, application logic, content management, responsive behavior, and deployment.

## ✦ Admin Dashboard

One of the main parts of this project is the custom administration experience.

The dashboard was designed so website content can be updated through an interface rather than requiring direct changes to the source code.

This helped turn the project from a static website into a more practical system that can be maintained after deployment.
